# Verdant Commerce OS

Verdant Commerce OS is a mini dashboard web application developed as part of a frontend machine test. The project demonstrates the ability to build a pixel-perfect UI, write clean and scalable React + TypeScript code, and integrate APIs while strictly following the provided design system.

---

## Objective

This project evaluates the following skills:

- Converting design requirements into a production-ready UI
- Writing maintainable and scalable React + TypeScript code
- Using Tailwind CSS effectively
- Integrating APIs with proper UX handling
- Building responsive dashboard layouts

---

## Tech Stack

- React (Vite)
- TypeScript (Strict Mode)
- Tailwind CSS
- Inter Font
- Fake Store API
- Framer Motion
---

## Design Guidelines Followed

- Primary Color: #22C55E
- Font: Inter
- Clean and modern UI
- Rounded cards with soft shadows
- Consistent spacing and alignment
- Fully responsive layout

---

## Features Implemented

### Dashboard Page
- Sidebar navigation (Dashboard, Products, Add Product)
- Header with user information
- Stat cards:
  - Total Products
  - Orders
  - Revenue

### Product Listing Page
- API Integration:
  https://fakestoreapi.com/products
- Displays product image, title, price, and category
- Search functionality
- Loading and error states
- Responsive grid layout

### Add Product Page
- Form fields:
  - Product Name
  - Price
  - Category
  - Image URL
- API Integration:
  https://fakestoreapi.com/products
- Client-side validation
- Success and error feedback

### Order and Revenue
 https://fakestoreapi.com/carts
